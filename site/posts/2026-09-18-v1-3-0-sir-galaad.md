Quandela published **v1.3.0** (v1.3.0 Sir Galaad) of Perceval.

Release notes (abridged, see the full notes at the source link):

This update offers a whole new error mitigation feature, which needed a complete rewriting of the high-level classes of perceval (everything above Processor or RemoteProcessor). This new path also offers a lot of features that the old path couldn't do.
The choice has been made to add a new main path for launching computations, while keeping the existing path as it is. The old path **should not** be used in new code anymore. You will find in the legacy page of the doc a table describing how to update the old workflow to the new one (link at the bottom of this text). 

## New features

* Error Mitigation classes:
  * Can be inserted into a Computer for automatic use.
  * Mitigates the probabilistic results got when using a QPU.
  * Available algorithms:
    * Detector loss balancing
    * HOM/g2 mitigation
    * Loss mitigation
    * Compilation averaging
  * Available as individual classes or through the ErrorMitigationFactory class.
